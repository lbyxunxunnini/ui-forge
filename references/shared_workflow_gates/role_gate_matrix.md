# Role Gate Matrix

## 需求分析师 Gate

### 仅允许进入

- 从需求、重设计目标、页面规划、设计诊断开始
- 在读取上下文、design card、记忆后收口 brief

### 必须停机

- 关键逻辑、内容来源、主 CTA、边界态未补全
- `goal_state / scope_state / acceptance_state / constraints_state` 任一未确认
- 当前 brief 与截图、文件、历史规则冲突

### 放行条件

- 用户确认状态允许进入 UI 设计阶段
- `Design Task Brief` 已形成
- `current_work_unit` 已明确
- `work_unit_state = frozen`

### 明确禁止

- 用推荐方案替代用户确认
- brief 未闭环时放行
- 因预算用完强行收口

## UI设计师 Gate

### 仅允许进入

- 需求已确认
- 已存在足够可靠的视觉输入或清晰文字结构
- 若视觉输入不可读，已启动 Visual Understanding Fallback，且已有足够文字、DOM/CSS 或设计规范证据
- 当前工作单元已冻结

### 必须停机

- 视觉输入不可读，且未启动 Visual Understanding Fallback 或没有可替代的文字、DOM/CSS、设计规范证据
- 多种拆法都合理且会影响结构方向
- 发现需要扩到新页面、新模块、设计系统层
- 图片生成或外部图片不可用，但尚未明确媒体资产策略
- 模型/环境无法读取图片、截图或画布，但尚未明确视觉理解降级策略

### 放行条件

- 布局、组件边界、交互状态足够支撑交付或前端实现
- App/iOS 页面已符合 iPhone 15 画布、顶部安全区、底部安全区和纵向滚动规则
- 每个首屏已有唯一主焦点和可追踪的 `focus_chain`
- 不存在会改变骨架的未决项
- 关键状态已覆盖
- 若触发 SVG Visual Fallback，已明确替代策略、资产目录和不伪造真实图片边界
- 若触发 Visual Understanding Fallback，已明确证据来源和不可验证的视觉项

### 明确禁止

- 未闭环就输出完整方案或代码
- 顺手扩范围
- 当前子单元未验证就推进下一页
- 用廉价占位图替代失败的图片生成

## 视觉审查师 Gate

### 仅允许进入

- UI设计师输出设计方案后
- 当前审查对象与 `current_work_unit` 对齐

### 必须停机

- 总分 < 20
- 任一维度 <= 1
- App/iOS 页面内容与状态栏、灵动岛、Tab 栏、底部操作栏或 Home Indicator 重叠
- 缩略/眯眼测试下看不出首屏主焦点
- `focus_chain` 缺失，或与实际视觉动作不一致
- 必改项未验证
- SVG Visual Fallback 伪造真实图片，或缺少基本资产质量说明
- 无视觉能力时声称完成真实截图、像素或缩略/眯眼审查

### 放行条件

- 总分 >= 20，且无维度 <= 1
- App/iOS 页面设备画布和安全区域审查通过
- 首屏主焦点、主内容、主 CTA 优先级清楚
- `20-23` 必须标注需优化项
- 审查对象不存在结构性未决项
- SVG Visual Fallback 已通过附加门禁（如触发）
- Visual Understanding Fallback 已标注证据来源和未直接验证项（如触发）

### 明确禁止

- 虚高打分
- 代替 UI设计师继续设计
- 未验证修改项就放行

审查轮次：最多 2 轮修改，第 3 轮升级为需求分析师决策。
详细评分标准：[visual_reviewer.md](../roles/visual_reviewer.md)

## 交付阶段 Gate

### 仅允许进入

- 视觉质量门禁通过
- 用户已明确确认设计方案
- 本轮目标仍与 brief 对齐

### 必须停机

- 设计方案尚未获得用户确认
- 仍存在会影响页面形态、组件状态或设计系统的未决项
- 发现“文件已生成但目标未达成”的假完成
- 验证前就试图结束

### 放行条件

- 产物结构、设计说明、状态覆盖和完整性检查通过
- `verification_state = verified`
- `exit_permission = true`

### 明确禁止

- 用“文件齐了”替代“任务完成”
- 跳过验证直接结束
