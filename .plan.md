# ui-forge SVG 优化提示词补充计划

## 背景分析

ip-designer 已有成熟的 SVG Generation Prompt 模板（填空式），包含 Canvas、Subject、SVG implementation、Style、Quality bar、Negative constraints 六大模块。ui-forge 有完整的 SVG 策略框架（fallback 策略、6 种风格映射、高美感构成要求、审查门禁），但缺少**可直接填空使用的 Prompt 模板**。

**目标：** 将 ip-designer 的 prompt 模板思路移植到 ui-forge，按 UI 场景定制，补充 3 类 prompt 模板 + 6 种风格细化规范。

## 变更清单

### 1. 新建 `references/svg_generation_prompts.md`（核心新增）

包含以下内容：

#### 1.1 SVG Icon 生成 Prompt 模板
用于 `icons/` 目录的功能图标生成，填空式模板：

```
Generate a clean SVG icon named {icon_name}.svg.
Canvas: viewBox="0 0 {24|48|64}". Output exactly one SVG file.

Subject:
- Icon purpose: {功能描述，如"手机号输入框前缀图标"}
- Semantic meaning: {语义，如"phone / mobile"}
- Style: {线框/填充/双色}
- Stroke width: {1.5px|2px}
- Color: currentColor（默认）或 {指定色值}

SVG implementation requirements:
- Use <path> as primary shape, supplement with <circle>, <rect>, <line>
- Keep paths clean and minimal (target: under 5 path commands)
- Use stroke-linecap="round" stroke-linejoin="round" for rounded icons
- Add <title>{icon description}</title> for accessibility
- All styling self-contained, no external references
- Use <defs> for reusable sub-shapes if needed

Quality bar:
- Pixel-perfect at 24px render size
- Optical center aligned (not just bounding box center)
- Consistent visual weight with other icons in the set
- Recognizable silhouette at 16px

Negative constraints:
- No gradients (icons should be single-color or currentColor)
- No filters or blur effects
- No text or labels inside the icon
- No clipPath or mask (keep paths clean)
- No stroke widths below 1px or above 3px
```

#### 1.2 SVG Visual Asset 生成 Prompt 模板
用于 `visuals/` 目录的插画/背景/空状态生成：

```
Generate a high-quality SVG visual asset named {asset_name}.svg.
Canvas: viewBox="0 0 {width} {height}". Output exactly one SVG file.

Subject:
- Purpose: {插画/背景/空状态/hero装饰/数据可视化}
- Scene description: {场景描述}
- Mood: {情绪关键词}
- Color palette: {主色/辅色/点缀色，含 HEX，来自 tokens.json}
- Style: {glass|editorial|data|geometric|neumorphic|neon}

SVG implementation requirements:
- Use layered <g> groups with clear ids: background, midground, foreground, accents, highlights
- Use <path>, <circle>, <ellipse>, <polygon> for shapes
- Use <linearGradient>, <radialGradient> for color transitions
- Use <clipPath>, <mask> for composition and reveal effects
- Use <filter> sparingly: feDropShadow, feGaussianBlur (max 2-3 filter nodes)
- Reuse shapes via <defs> + <use>
- Add <title> and <desc> describing the asset

High-aesthetics requirements (use at least 3 of 6):
- Gradients: linearGradient, radialGradient, opacity highlights, gradient strokes
- Filters: feDropShadow, feGaussianBlur, feTurbulence, feColorMatrix
- Masks: clipPath, mask, gradient transparency layers
- Paths: bezier curves, waveforms, data lines, segmented rings, irregular containers
- Reuse: defs, symbol, use, named layers
- Texture: inner shadows, highlight strokes, noise texture, local glow

Quality bar:
- At least 6 meaningful color levels
- Visible depth through layering (not flat)
- Balanced composition with clear focal point
- Consistent with page tokens and brand palette
- File size under 50KB

Negative constraints:
- No dense repeated <rect> grid
- No placeholder gray boxes
- No full-screen gaussian blur
- No text converted to paths (keep <text> for UI text)
- No clipPath covering entire canvas
```

#### 1.3 六种风格各自的 SVG Prompt 细化

**glass 风格：**
```
Style-specific requirements for glass:
- Semi-transparent surfaces with backdrop-filter: blur() equivalent in SVG
- Use feGaussianBlur on background layers, then overlay with opacity 0.6-0.8 shapes
- Highlight strokes: 1px white/light stroke at 20-40% opacity on top edges
- Soft shadows: feDropShadow with low dx/dy, high stdDeviation, low opacity
- Layer order: blurred bg → glass surface → content → highlight edges
- Avoid: solid opaque fills, harsh edges, high-contrast borders
```

**editorial 风格：**
```
Style-specific requirements for editorial:
- Asymmetric path compositions, large geometric shapes as visual anchors
- Muted accent colors (low saturation, high contrast with background)
- Use clipPath for image-mask-like reveals
- Typography blocks as compositional elements (but keep as <text>)
- Generous whitespace, intentional negative space
- Avoid: symmetric layouts, busy decorations, gradients overload
```

**data 风格：**
```
Style-specific requirements for data visualization:
- Ring/arc progress indicators using stroke-dasharray on <circle>
- Grid lines with low-opacity strokes
- Curve charts using <path> with smooth bezier commands
- Bar charts with rounded corners (rx/ry on <rect>)
- Status dots with subtle glow (feDropShadow with colored shadow)
- Micro-light trails: thin strokes with gradient opacity
- Avoid: 3D effects, decorative elements that distract from data
```

**geometric 风格：**
```
Style-specific requirements for geometric:
- Large shape combinations: circles, triangles, rectangles as primary forms
- Hard-edge masks with clipPath for shape intersections
- High-contrast color blocks (2-4 bold colors)
- Structural whitespace as design element
- No gradients or minimal single-direction gradients
- Avoid: soft shadows, blur effects, organic curves
```

**neumorphic 风格：**
```
Style-specific requirements for neumorphic:
- Inner shadows for pressed state: inset light on top-left, inset dark on bottom-right
- Raised elements: light shadow top-left, dark shadow bottom-right
- Low-contrast background (#e0e5ec or similar light neutral)
- Subtle highlights: 1px semi-white stroke on top edges
- All elements share same background color family
- Avoid: strong borders, high contrast, saturated colors
```

**neon 风格：**
```
Style-specific requirements for neon:
- Dark background (#0a0a0a to #1a1a1a)
- Glowing strokes: use feGaussianBlur + feMerge for glow effect
- Multiple transparent stroke layers for depth (3-4 layers, decreasing opacity)
- High-saturation accent colors (cyan #00fff5, magenta #ff00ff, lime #00ff88)
- Thin base strokes (1-2px) with wide glow (blur 4-8px)
- Avoid: solid fills, flat colors, white backgrounds
```

#### 1.4 量化质量指标表

| 维度 | 最低要求 | 推荐值 |
|------|---------|--------|
| 矢量元素多样性 | ≥3 种类型 | ≥5 种（path+circle+rect+gradient+filter） |
| 色彩层次 | ≥4 色阶 | ≥6 色阶 |
| 分层 <g> 组 | ≥3 层 | ≥5 层（bg/mid/fg/accent/highlight） |
| 滤镜使用 | 0-2 个 | 1-3 个（避免过多影响性能） |
| 渐变使用 | ≥1 个 | ≥2 个（linear+radial） |
| <defs> 复用 | ≥1 个 | ≥2 个 |
| 文件大小(icon) | ≤5KB | ≤3KB |
| 文件大小(visual) | ≤50KB | ≤30KB |

#### 1.5 分类负面约束汇总

| 类型 | 禁止项 |
|------|--------|
| icons/ | 无渐变、无滤镜、无文字转曲、无 clipPath、无 stroke<1px |
| visuals/ | 无 rect 网格、无灰色占位、无全屏模糊、无伪造真实图片 |
| glass | 无不透明填充、无硬边、无高对比边框 |
| editorial | 无对称布局、无过度装饰、无渐变滥用 |
| data | 无 3D 效果、无干扰数据的装饰元素 |
| geometric | 无柔和阴影、无模糊效果、无有机曲线 |
| neumorphic | 无强边框、无高对比、无饱和色 |
| neon | 无纯色填充、无白色背景、无粗线条 |
